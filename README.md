# Leaderify

Leaderify é uma aplicação para criar **rankings personalizados sobre qualquer coisa que o usuário quiser**.

Em vez de ser limitado a um domínio específico — como esportes, filmes ou linguagens de programação — a aplicação permite que os usuários criem seus próprios **Rankings**, definam o que desejam avaliar e decidam como o ranking deve ser apresentado.

## Conceito principal

Um **Ranking** contém uma coleção de **Itens** que são avaliados através de uma ou mais **Métricas**.

Por exemplo, um usuário poderia criar:

> **Melhores linguagens de programação**

com os seguintes Itens:

- Java
- Python
- Rust
- C++

e Métricas como:

- Performance
- Tempo de Compilação
- Uso de Memória
- Curva de Aprendizado

Cada Item recebe um **Valor** para cada Métrica, que será utilizado para ordenar o Ranking seguindo as configurações feitas pelo usuário.

## Organização flexível

Os Itens também podem possuir **Tags**, que descrevem características relacionadas a eles, em vez de medir seu desempenho.

Por exemplo:

- `Execução → Compilada`
- `Execução → Interpretada`
- `Paradigma → Orientada a Objetos`
- `Paradigma → Funcional`

Tags podem ser utilizadas para **filtrar e agrupar Itens**, permitindo explorar um Ranking de diferentes maneiras.

## Visualizações

Um Ranking pode possuir várias **Visualizações**, permitindo que os mesmos dados sejam explorados de diferentes formas.

Uma Visualização pode definir:

- Quais Métricas são visíveis
- Ordenação
- Filtros
- Agrupamento
- Como os Itens são apresentados

Por exemplo, o mesmo Ranking de linguagens de programação poderia possuir:

- **Melhor Geral**
- **Melhor desempenho**
- **Amigável para iniciantes**
- **Baixo uso de memória**

As Visualizações não armazenam cópias dos dados do Ranking. Elas são configurações para visualizar os mesmos Itens, Métricas, Valores e Tags.

As Visualizações também podem ser **pessoais ou compartilhadas**, permitindo que diferentes membros do mesmo Ranking tenham suas próprias perspectivas sobre os dados.

## Recursos sociais e colaboração

Usuários podem colaborar entre si na elaboração de Rankings, para isso, basta o Criador do ranking enviar um convite para outro usuário.

Os Criador do ranking também pode designar papéis para os participantes, que definem o que eles podem e não podem fazer naquele ambiente.

Por fim, os usuários também podem adicionar uns aos outros, formando um vínculo de **Amizade**, que facilita futuras colaborações.

## Em resumo

> **Ranqueie qualquer coisa, usando seus próprios critérios, e explore o ranking da maneira que quiser.**
